Análisis Exploratorio de Datos del Titanic

Un proyecto completo de Ingeniería de Datos que incluye análisis exploratorio, visualización y modelos predictivos para predecir la supervivencia de los pasajeros del Titanic.

🚀 Ver Paso a Paso 📦 Ver en GitHub

📊 Paso a Paso del Análisis

Metodología utilizada en el proyecto

1
📁

Seleccionar Dataset

Se utiliza el dataset del Titanic de Kaggle, que contiene información de 418 pasajeros con 12 características cada uno.

2
📥

Importar Datos

Se importan los datos usando pandas y se cargan desde Kaggle utilizando la librería kagglehub.

3
🧹

Limpiar Datos

Se identifican y tratan los valores faltantes: Age (86 valores), Fare (1 valor), Cabin (327 valores).

4
📈

Analizar Datos

Análisis estadístico descriptivo, visualización de datos y tablas de frecuencia.

5
🤖

Modelos ML

Aplicación de modelos de Machine Learning para predicción de supervivencia.

6
💡

Tomar Decisiones

Interpretación de resultados y conclusiones basadas en el análisis.

🔍 Características del Dataset

Variables disponibles en el análisis

🆔

PassengerId

Identificador único para cada pasajero

💚

Survived

Variable objetivo: Supervivencia (0 = No, 1 = Sí)

🎫

Pclass

Clase del billete (1ª, 2ª o 3ª)

👤

Name

Nombre completo del pasajero

⚥

Sex

Género del pasajero (male/female)

🎂

Age

Edad del pasajero (0.17 - 76 años)

👨‍👩‍👧

SibSp

Hermanos/Cónyuges a bordo

🏠

Parch

Padres/Hijos a bordo

🎟️

Ticket

Número del billete

💰

Fare

Tarifa pagada (0 - 512.33)

🚪

Cabin

Número de cabina

⚓

Embarked

Puerto: C (Cherbourg), Q (Queenstown), S (Southampton)
